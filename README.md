# C# Client-Server Chat System

## Overview

PROTOCHAT is a console-based client/server chat application developed in C# to experiment with TCP networking, socket communication, multithreading, and real-time messaging systems.

The application allows users to either:

* Host a chat server on a chosen port
* Connect to an existing server as a client using an IP address and port

This project was developed independently as part of personal learning and experimentation with networking concepts in C#.

---

## Features

* TCP client/server communication
* Console-based user interface
* Custom username support
* Multi-client messaging system
* Broadcast messaging between connected users
* Threaded client handling
* User-selectable ports for hosting and connecting

## Technologies Used

## Purpose of the Project

This project was created to strengthen understanding of:

* Networking fundamentals
* TCP/IP communication
